FAQ

Frequently Asked Questions

Everything you need to know about Codex Auth Exporter.

Why does Codex ask me to sign in again, and how does this help?
Codex can ask you to sign in again when browser sessions expire or security checks change. This extension lets you log in to ChatGPT normally, then locally export the active session as auth.json for your own Codex config.
Is this extension safe? Will it leak my ChatGPT account Session?
The extension is designed to run inside the local browser sandbox with no external server sync endpoints. Source code is open on GitHub so you can inspect how session data is read and exported.
How long does my auth info remain valid?
The validity period depends entirely on the OpenAI ChatGPT Session lifespan. Typically sessions last two weeks to one month. The extension automatically parses the expires field with millisecond precision, and the mockup panel shows exactly how long until expiry. When expired, simply click once to re-export.
Which browsers are supported?
All Chromium-based browsers are supported, including Google Chrome, Microsoft Edge, Arc, Brave, Opera etc. Simply enable "Developer mode", select "Load unpacked", and import the root folder containing manifest.json.
