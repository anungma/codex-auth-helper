Core Security Assurances

We uphold the following three user privacy pledges, with data fully under your local control:

Zero Network Upload

All data processing and config file packaging happens entirely within your local browser sandbox, with no network sync or upload behavior.

Zero Data Retention

The extension only processes Session data momentarily in memory with no local database persistence. Data is completely destroyed when memory is freed or the extension is uninstalled.

Zero Third-Party Disclosure

We never share, sell, or transfer any user data to third parties, advertisers, or data analytics organizations, strictly adhering to compliance standards.

Data Collection Declarations

We do not collect any user data. This extension is a purely local, offline utility. It does not collect, record, or transmit your personally identifiable information (PII), geolocation, device identifiers, browser history, and does not include any third-party trackers or analytics SDKs.

When you actively use the "One-Click Extract" feature, the extension only reads your currently logged-in ChatGPT session credentials (Session Token) in memory and performs local format parsing, to assemble and write it into your exported auth.json file. This process involves absolutely no data exchange with any external service.

We do not collect any user data. The Extension operates completely offline. We do not collect, store, or transmit your personally identifiable information (PII), geolocation, browser history, or account credentials. When you actively trigger the capture feature, the ChatGPT session token is temporarily accessed in-memory solely for local parsing and file download.

Permission Usage & Justification

To implement the core session config file export feature, the extension declares the following necessary permissions in manifest.json. We clearly disclose the specific justified use of these permissions here, with no abuse or overreach:

Permission / Host Permission Permission Level Justified Use / Justification
downloads Moderate Allows the extension to locally generate an auth.json file and automatically invoke the browser download sandbox to save it to your designated local download directory. This action is 100% triggered manually by the user, with no silent background or unauthorized file downloads.
https://chatgpt.com/ Sensitive Host Access Allows the extension to make cross-origin requests to ChatGPT where the user is already logged in, to extract the existing login Session in the current browser. We only access this specific domain, without touching or interfering with any other external web page data.
We only request the absolute minimum permissions needed for core features. The `downloads` API is used strictly to save the locally generated 'auth.json' config file, triggered solely by clicking the download button. The host permission on `https://chatgpt.com/` is required solely to fetch the current authenticated session cookie for local backup, without touching any other websites.

Data Security & Transparency

To ensure maximum data security, the extension employs the following security mechanisms:

  • Pure In-Memory Processing: After your ChatGPT login credentials are captured, they are only temporarily parsed in the extension runtime memory and immediately released. The extension does not use databases or local storage (such as localStorage / Chrome Storage) for persistent storage.
  • Closed-Loop Data Download: The extension uses closed-loop Data URL encoding to directly output the config file as a download stream, meaning all data conversion happens entirely within the browser sandbox environment, with no data exfiltration channel.
  • Fully Open Source & Transparent: The extension source code is publicly available on GitHub. Anyone can independently review and security-audit our extension logic.
To guarantee security, your credentials exist strictly in-memory during packaging and are immediately released. No local persistent storage (localStorage/chrome.storage) is used. The 'auth.json' is compiled into a Data URL for sandboxed local download, ensuring a closed loop. The source code is open and audited.
