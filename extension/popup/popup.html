Usage Instructions
1
Step 1: Export Workspace Auth

Click "Export Current Account" for the selected ChatGPT account, or "Export All Accounts" to download one backup file per active personal/workspace account.

2
Step 2: Rename and Move to Codex Config Directory

To use the exported backup with Codex, rename or copy it to auth.json in your local Codex configuration directory:

Windows: %USERPROFILE%\.codex\auth.json

macOS: ~/.codex/auth.json

3
Step 3: Launch Codex

Once the file is in place, simply start or restart your Codex client. Authorization will be loaded automatically from your local config.
